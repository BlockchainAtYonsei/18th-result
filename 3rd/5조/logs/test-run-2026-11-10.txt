
  BAY AML Demo - ReasonedFreeze
    실험 1. 등록된 사용자만 수신할 수 있는가
      ✔ A -> B (등록된 수신자) 전송은 성공한다
      ✔ A -> C (미등록 수신자) 전송은 "Transfer not possible" 로 실패하고 잔액이 유지된다
    실험 2. 근거와 함께 동결하면 차단되고, 해제하면 재개되는가
      ✔ 동결 시 사유, 근거 해시, 운영자, 만료 시점이 기록된다
      ✔ 동결된 B 는 수신(A -> B)도 송신(B -> A)도 "wallet is frozen" 으로 실패하고 잔액이 유지된다
      ✔ 운영자가 해제 사유와 함께 해제하면 전송이 재개되고, 기록은 지워지지 않는다
    실험 3. 근거 없는 동결과 무권한 조치는 거부되는가
      ✔ 근거 해시가 없거나 기한이 0 이거나 최대 기간을 넘으면 동결할 수 없다
      ✔ 일반 사용자 A 는 B 를 동결할 수도, 해제할 수도 없고 동결 상태는 유지된다
    실험 4. 만료된 동결은 운영자 없이도 풀리는가
      ✔ 만료 후에는 동결 당사자 B 가 직접 해제할 수 있고 전송이 재개된다
      ✔ 기한을 연장하려면 새 근거가 필요하고, 연장하면 기존 만료 시점에는 풀리지 않는다
    한계. 이 래퍼가 막지 못하는 경로
      ✔ Agent 의 forcedTransfer 는 동결된 B 의 토큰도 옮긴다
      ✔ 다른 Agent 가 토큰에 직접 동결하면 근거 기록 없이도 집행된다
