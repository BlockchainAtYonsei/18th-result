# 에이전트 작업 지침

이 지침은 저장소 전체에 적용합니다.

## 커밋 메시지 규칙

모든 커밋 메시지는 다음 형식을 따릅니다.

```text
type(subtype): 한국어 요약

- 한국어 본문
```

- 유형(`type`)과 세부 유형(`subtype`)은 영어로 작성합니다.
- 세부 유형은 생략하지 않습니다.
- 요약과 본문은 한국어로 작성합니다.
- 제목과 본문 사이에는 빈 줄을 둡니다.
- 본문은 `- `로 시작하는 불릿을 하나 이상 작성합니다.
- 유형과 세부 유형은 실제 변경 내용을 설명하도록 선택합니다.

예시:

```text
chore(init): 프로젝트 초기 구조와 에이전트 작업 지침 추가

- 앱, 서비스, 계약 및 시뮬레이션의 초기 파일 구조 추가
- 에이전트와 Claude가 참고할 커밋 메시지 규칙 문서화
```
