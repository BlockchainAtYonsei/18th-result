# Moa 저장소 작업 규칙

## 커밋 메시지

이 저장소에서 만드는 모든 커밋은 다음 형식을 사용한다.

```text
유형(세부유형): 한국어 요약

- 불릿텍스트 한국어 본문
```

- 제목은 `유형(세부유형): 한국어 요약` 형식으로 작성한다.
- 제목 다음에 빈 줄을 한 줄 둔다.
- 본문은 한국어 불릿 목록으로 작성한다.
- 본문의 각 불릿은 명사형으로 끝낸다.
- 변경 사항이 여러 개라면 각 항목을 별도의 `-` 불릿으로 구분한다.

예시:

```text
chore(setup): 모노레포 초기 개발 환경 구성

- pnpm 워크스페이스와 공통 설정 추가
- Hardhat 기반 컨트랙트 개발 환경 구성
```
