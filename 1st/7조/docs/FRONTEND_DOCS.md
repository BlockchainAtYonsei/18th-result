# 크리에이터 수익 브릿지 - 프론트엔드 Happy Path 데모 구현 계획

본 문서는 프론트엔드의 Happy Path 데모 완성을 위한 세부 구현 계획을 담고 있습니다.
각 단계는 하나의 기능(Feature)을 담고 있으며, 하나의 Git 커밋으로 처리될 단위입니다.

## 🎯 최종 목표
수익권 상품 확인부터 투자, 정산, 수익 청구까지 이어지는 전체 흐름을 브라우저에서 실제 트랜잭션으로 구동하는 것.

---

## 📝 단계별 구현 계획 (커밋 단위)

### 1단계: 프로젝트 환경 세팅
**Commit:** `build(frontend): Web3 및 기본 UI 환경 설정`
- **목표:** 블록체인 통신과 UI 구성을 위한 기본 라이브러리 설치 및 세팅
- **작업 내용:**
  - `viem`, `wagmi`, `@tanstack/react-query` 설치 및 Provider 세팅
  - 간단한 UI 구현을 위한 `lucide-react`(아이콘) 설치
  - 컨트랙트 주소 및 로컬 Anvil 네트워크(ChainId: 31337) 환경 변수 세팅

### 2단계: 지갑 연결 기능
**Commit:** `feat(frontend): 지갑 연결 및 잔액 조회 기능 구현`
- **목표:** 투자자가 브라우저 지갑을 연결하고 상태를 확인할 수 있는 컴포넌트 개발
- **작업 내용:**
  - 우측 상단 지갑 연결 / 해제 버튼 구현
  - 연결된 지갑 주소 단축 표시 (예: 0x90F7...1234)
  - 사용자의 mUSD 잔액 조회 및 표시
  - Anvil 네트워크 연결 여부 경고 표시

### 3단계: 데모 상품 상세 화면 UI
**Commit:** `feat(frontend): 데모용 상품 상세 정보 화면 구현`
- **목표:** 투자할 상품의 오프체인 정보와 온체인 정보를 결합하여 표시
- **작업 내용:**
  - 크리에이터 정보, 과거/예상 수익, 위험 안내 등 프론트엔드 내 하드코딩된 목업(Mock) 데이터 정의 (백엔드 연결 전 임시)
  - 컨트랙트에서 총 모집 수량, 현재 모집 수량, 모집 상태(Funding 등) 조회하여 표시
  - 상품 정보 카드 컴포넌트 퍼블리싱

### 4단계: 투자 승인 (Approve) 기능
**Commit:** `feat(frontend): mUSD 투자 승인(Approve) 기능 구현`
- **목표:** 투자를 위해 스마트 컨트랙트가 사용자의 mUSD를 가져갈 수 있도록 권한 부여
- **작업 내용:**
  - 투자 수량(mUSD) 입력 폼 구현
  - mUSD 컨트랙트의 `approve` 트랜잭션 호출 로직 작성
  - 트랜잭션 로딩 상태(승인 중...) UI 처리

### 5단계: 투자 (Invest) 기능
**Commit:** `feat(frontend): 수익권 투자(Invest) 트랜잭션 기능 구현`
- **목표:** 실제 상품에 투자하고 수익권을 발행받는 기능
- **작업 내용:**
  - `RevenueBridge` 컨트랙트의 `invest` 함수 호출
  - 승인(Approve) 완료 후 자동으로 투자 버튼 활성화 및 연계 로직
  - 트랜잭션 완료 후 "투자가 완료되었습니다" 상태 피드백 및 데이터 새로고침

### 6단계: 내 투자 내역 및 수익 청구
**Commit:** `feat(frontend): 투자 내역 조회 및 수익 청구 기능 구현`
- **목표:** 투자자가 자신의 포트폴리오를 확인하고 수익이 났을 때 청구하는 기능
- **작업 내용:**
  - 보유한 수익권(ERC-1155) 토큰 개수 및 투자 원금 조회 표시
  - 컨트랙트의 `claimable` 함수를 통해 현재 청구 가능한 수익(mUSD) 조회 표시
  - `claim` 함수를 호출하여 수익금 수령 트랜잭션 구현

### 7단계: 데모 운영자 컨트롤 패널
**Commit:** `feat(frontend): 데모 시나리오 진행을 위한 운영자 패널 추가`
- **목표:** 원활한 데모 시연을 위해 블록체인 상태를 조작하는 숨겨진 버튼 패널 구현
- **작업 내용:**
  - `finalizeFunding` (모집 확정) 버튼
  - `withdrawAdvance` (크리에이터 선지급금 수령) 버튼
  - 정산자 지갑 연결 및 mUSD `approve` -> `settlePeriod` (수익 정산) 버튼
  - `closeOffering` (상품 종료) 버튼
